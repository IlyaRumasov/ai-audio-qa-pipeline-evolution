Оригінальні флоу травня 2026 року, знеособлені: ID папок і таблиць, проєкт GCP, пошта й креди
замінені заглушками `<...>`. Логіку не змінено, тому тут видно і сильні сторони, і проблеми,
описані в головному README (розділи «Що було не так» та «Еволюція»).

- `v1-vertex-audio-audit.json`: конвеєр Drive → rclone → тимчасовий бакет GCS → JSONL (pandas)
  → Vertex AI Batch → збірка CSV (pandas) → Drive + HTML-лист. Керує хостом через SSH.
- `v1-ai-qa-bot.json`: синхронна перевірка Drive → Gemini → Google Sheets.

Не для запуску: замість них використовуйте `../audio-qa-batch-vertex.json` і `../audio-qa-sync.json`.
